# TOHEŞAR / MEMORY ALLOY — Stage 02

Status: **experimental first-scene proof**; not approved, not a live homepage, not a published portfolio work.

## Production constraints
- Entirely isolated at `/prototypes/memory-alloy-001/`; `main/index.html`, WORLD, SYMBOL, JOURNAL, HISTORY, CNAME and previous experiments remain unchanged.
- Shares only the official original `/assets/wordmark.svg` (rendered graphite using CSS) and MIT-licensed vendored Three.js r180 at `/next-generation/vendor/three/build/three.module.js`.
- Does **not** reuse the Se-diyu shape, CHROME ATMOSPHERE 3D loop, any car images, any commercial music or fabricated content.

## Experience
One pinned `275svh` sequence representing website progress 0–30%: asymmetrical satin-titanium folio, hinged metal wing, two transparent memory films, photographic softbox reflections and subtle mobile-first graphic typography. Scroll opens the wing, separates film, advances the camera toward the opening; reversing touch scroll reverses everything. Hero frame and motion are provisional art-direction candidates only.

## Review
Run in a web server **at the repository root** (absolute asset paths must resolve) and visit `/prototypes/memory-alloy-001/`. Do not launch `index.html` as file://. Query `?frame=0`, `?frame=.23`, `?frame=.65` or `?frame=1` freezes a particular progress for screenshots. Interactions: native vertical scroll, INDEX menu, pause motion, reduced-motion setting. No build or external CDN required.

## QA status
Code packaged and pushed to experiment branch. Browser/WebGL rendering has **not** been proven on an actual iPhone Safari. Required next: 390×844, 375×812, 430×932, iPad landscape visual frames; physical iPhone Safari scrolled forward/back; GPU memory/thermal check; subject and typography approval. The page is not part of GitHub Pages main unless specifically deployed to a separate preview environment.

## Aesthetic rejection criteria
Generic chrome blob/torus appearance, poor metallic reflection, unreadable approved Ş, meaningless motion without spatial opening, plastic-looking film, frame clipping or more than 2 seconds of forced intro. Do not build Scene 03 or a generic cards UI until Stage 02 passes visual review.

긴 앞부분은 반드시 엔진을 위한 것일까. 재규어 Type 01을 바라보면, 전기차가 얻은 자유를 어디에 쓸 것인지라는 질문이 먼저 떠오른다. 실내를 앞으로 밀어 공간을 극대화하는 대신, 이 자동차는 낮고 긴 차체에 존재감을 실었다.

Jaguar는 2026년 10월 6일 뉴욕에서 Type 01을 공개했다. 전용 전기차 구조인 JEA 위에 세운 새로운 4도어 GT다. 2024년 12월의 Type 00은 디자인 방향을 제시한 콘셉트였고, Type 01은 그 뒤를 잇는 첫 양산 모델로 발표됐다. 생산은 2027년 시작될 예정이다. [1–3]

달력의 두 지점을 잇는 것은 이름만이 아니다. 긴 보닛, 낮은 지붕, 넓게 남겨둔 차체 표면이 반복된다. 그러나 네 개의 문과 실제 생활을 위한 경계를 가진 Type 01은 콘셉트의 복제품도 아니다. 이 글은 그 사이에 남은 생각과 달라진 형태를 읽는다.

TWO CARS / TWO ROLES

Type 00 — 2024.12 / 디자인 비전 콘셉트

Type 01 — 2026.10 / 공개된 전기 4도어 GT, 2027년 생산 시작 예정

뉴욕 공개는 10월 6일, 영국 JLR·Jaguar 보도자료 발행은 10월 7일입니다. 주문·인도 일정은 발표 당시 계획입니다.
CHAPTER 02 / THE LONG BONNET

전기차에 남겨진,
긴 앞부분의 이유.

공간을 줄이는 기술이
오히려 긴 비례를
선택하게 할 수도 있다.

제조사가 Type 01의 비례를 설명하는 말은 구체적이다. 낮은 지붕선, 짧은 앞 오버행, 긴 보닛, 길게 뻗은 뒤 오버행, 23인치 휠. [3] 긴 보닛과 짧은 앞 오버행은 모순되지 않는다. 앞 오버행은 앞바퀴 축에서 차체 끝까지의 부분이고, 보닛의 길이는 앞쪽 차체와 캐빈의 관계에서 읽힌다. 앞바퀴를 끝에 가깝게 두면서도 앞유리가 시작되는 지점을 뒤로 물릴 수 있다.

공식 측면 사진에서는 지붕이 앞유리 뒤에서 낮게 이어지고, 뒷좌석 뒤로 내려오며 긴 후면 덩어리와 만난다. 옆창 아래로 넓게 남은 차체 면은 캐빈을 더 낮고 얇게 보이게 한다. 창의 높이를 실제로 재지 않아도, 어두운 유리 띠와 밝은 차체의 면적 차이가 이런 인상을 만든다.

전기 구동계라는 이유만으로 긴 보닛이 필연적인 것은 아니다. 오히려 이 선택은 여유와 이동의 감각을 비례로 표현하려는 태도로 읽힌다. 긴 차체가 먼저 보이고 실내는 그 안에 잠겨 있는 듯하다. 재규어의 GT를 기억하는 사람에게 익숙한 구도이면서, 공간 효율을 가장 먼저 기대하는 독자에게는 논쟁적인 선택이다.

CHAPTER 03 / A DIFFERENT LANGUAGE

기억을 잇는 것은
똑같은 선이 아니다.

재규어는 Type 01을 소개하며 E-type과 XJS를 계보로 언급한다. [1] 이 연결을 과거의 그릴이나 램프 모양을 그대로 옮겼다는 뜻으로 받아들이면 새 차의 성격을 놓친다. 이어지는 것은 특정 부품보다 긴 앞부분과 낮은 캐빈이 주는 태도다. 과거를 떠올리는 비례 위에서 표면을 다루는 방법은 바뀐다.

Type 00의 2024년 발표는 이 방향을 ‘Exuberant Modernism’이라고 불렀다. 재규어는 전기차 시장에서 서로 비슷해지는 형태를 벗어나고, 브랜드의 고객층과 위치까지 바꾸겠다고 설명했다. 2026년 JLR 자료 역시 Jaguar를 그룹 안의 다른 브랜드와 구별되는 전기차 브랜드로 자리매김한다. [2, 5] 새 언어는 동력원의 교체만을 표현하는 것이 아니라, 멀리서도 다른 차로 보이게 하려는 선택이다.

사진 속 Type 01의 후면에서는 창을 둘러싼 면과 어깨의 넓은 볼륨이 명확한 경계를 만든다. 둥근 덩어리를 유연하게 잇기보다, 넓은 면의 각도 차이로 빛을 나눈다. 이 차가 평평하다는 뜻은 아니다. 밝은 하이라이트가 모서리에서 접히고 그 아래 그늘이 길게 남기 때문에, 면의 변화가 더 또렷해 보인다.

제조사 FAQ는 프레임리스 도어와 창·차체 사이에 눈에 띄는 트림을 남기지 않는 처리를 강조한다. [4] 장식을 덜어낸 표면은 경계가 사라진 것처럼 보이지만, 실제로는 경계를 얼마나 정밀하게 정리했는지에 기대고 있다. Type 01의 간결함은 요소의 부재보다 접합부를 다루는 방식에서 읽는 편이 정확하다.

04 / THE COMPARISON

형태를 복제하지 않고,
생각을 이어받는 방법.

공식 이미지의 프레임과 방향을 그대로 두었습니다. 서로 다른 촬영 조건이므로 길이·높이의 수치 비교가 아닌, 형태의 관계를 읽는 자료입니다.

01 / PROPORTION

이어지는 비례

Type 00의 긴 보닛과 낮은 지붕, 뒤로 흐르는 실루엣은 Type 01에서도 핵심이다. 공식 사진에서는 두 모델 모두 옆창보다 차체 면의 존재감이 먼저 읽힌다. 이것은 선이 완전히 같다는 주장이 아니라, 요소 사이의 위계가 이어진다는 관찰이다.

02 / DAILY LIFE

달라지는 경계

Type 00의 버터플라이 도어와 단순한 옆창은 하나의 조형물 같은 인상을 만든다. Type 01에서는 앞뒤 문과 옆창의 구획, 외부 미러가 눈에 들어온다. 네 명의 이동을 위한 구조를 수용하면서도 면을 깨끗하게 유지하려는 방향이 보인다.

03 / SURFACE & GRAPHIC

선언과 조정

Type 00의 유리 없는 테일게이트와 수평 Strikethrough 그래픽은 2024년 콘셉트의 특징으로 명시됐다. 이를 Type 01의 확정 사양으로 옮겨 적어서는 안 된다. Type 01 발표는 깨끗한 표면과 능동형 베인·전개식 스포일러를 함께 설명한다. 조형의 순수함과 공기 흐름을 실제 차에서 조정해야 하는 단계다. [3, 5]

실내의 번역은 더 구체적이다. Type 00에는 황동, 트래버틴과 직물, 실내를 길게 가르는 중심 구조가 제안됐다. Type 01의 공식 설명은 황동을 연상시키는 양극산화 알루미늄 마감재와 트래버틴에서 영감을 얻은 색조를 말한다. [3–5] 돌과 금속의 이름이 반복된다고 소재와 제작 방식까지 같다고 볼 수는 없다. 감각의 주제는 이어지지만, 양산차에서는 그것을 구현하는 재료와 사용성이 다시 설계된다.

콘셉트에서 양산 모델로 가는 일은 과감함을 조금씩 덜어내는 단순한 과정이 아니다. 무엇을 남겨야 처음의 인상이 살아나는지 선택하는 작업에 가깝다. Type 01에서는 긴 비례와 넓은 면이 그 역할을 맡는다. 반대로 도어의 구획과 공기 흐름을 조절하는 장치들은, 하나의 선언이 실제 자동차가 되기 위해 받아들인 조건을 드러낸다.

CHAPTER 05 / WHAT CHANGES

미래의 형태는,
하나일 필요가 없다.

낯선 표면 위에
익숙한 비례를 남긴다.
그 선택의 결과는
아직 열려 있다.

Type 01의 조형적 강점은 정보의 위계를 분명하게 정했다는 데 있다. 먼저 낮고 긴 덩어리가 보이고, 그다음 큰 바퀴와 어두운 유리, 마지막으로 얇은 경계와 표면의 빛이 읽힌다. 많은 선을 더해 속도를 표현하기보다, 긴 면과 작은 캐빈의 대비가 자동차의 성격을 먼저 말한다.

그 선명함은 동시에 질문을 만든다. 넓은 차체 면과 낮은 유리의 비율이 어떤 사람에게는 단단한 존재감으로, 다른 사람에게는 시각적인 무게로 다가올 수 있다. 긴 보닛을 유지하는 선택 역시 재규어의 GT를 기억하게 하지만, 전기차 구조로 얻은 자유를 얼마나 새로운 생활 방식으로 돌려줬는지 묻게 한다. 이 질문은 사진만으로 실제 거주성이나 시야를 판정하는 것과는 다르다.

여기서 중요한 변화는 전기차에 단 하나의 올바른 비례가 있다고 보지 않는 태도다. Type 01은 전동화를 과거의 비례를 지우는 이유로만 쓰지 않는다. 과거의 긴장감을 다른 표면과 그래픽으로 표현할 수 있는 조건으로 삼는다. 911이 곡선의 연속성을, F40이 기능의 노출을 통해 정체성을 만든다면, 이번 재규어는 비례의 기억과 표면의 단절을 한 차체 안에 함께 놓는다.

이 선택이 디자인사에서 어떤 평가를 받을지는 아직 정해지지 않았다. 실제 도로에서의 모습, 시간에 따른 수용, 뒤따를 모델들이 그 판단을 바꿀 것이다. 지금 확인할 수 있는 것은 Type 00의 선언이 Type 01이라는 구체적인 4도어 GT로 이어졌다는 사실이다. 자동차의 미래를 이해하는 일은 새 모양을 외우는 것보다, 무엇을 남기고 무엇을 바꿨는지 묻는 데서 시작된다.

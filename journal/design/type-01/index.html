CHAPTER 01 / THE NEW ARRIVAL

새로운 시대는
어떤 형태로 오는가.

JAGUAR
Type 01.

긴 보닛과 낮은 지붕. 익숙한 GT의 기억이
낯선 표면 위로 다시 떠오른다.

© Jaguar Land Rover Limited · WebP 변환 · 모바일 화면 크롭 Type 01 공식 이미지 / JLR User Licence
글·디자인 해석 TOHEŞAR / 약 9분

전기차에는 앞쪽에 큰 엔진을 넣을 이유가 없다. 그런데 Type 01의 보닛은 길다. 공식 측면 사진에서 앞유리가 시작되는 지점은 앞바퀴 축보다 꽤 뒤에 있다. 실내를 앞으로 당겨 공간을 넓히는 길도 있었을 것이다. 전기차가 얻은 자유를 Type 01은 낮고 긴 차체에 썼다.

Jaguar는 2026년 10월 6일 뉴욕에서 Type 01을 공개했다. 전용 전기차 구조인 JEA 위에 세운 새로운 4도어 GT(장거리를 빠르고 편안하게 달리는 차)다. 2024년 12월의 Type 00은 디자인 방향을 제시한 콘셉트였고, Type 01은 그 뒤를 잇는 첫 양산 모델로 발표됐다. 생산은 2027년 시작될 예정이다. [1–3]

CHAPTER 02 / THE LONG BONNET

긴 보닛,
짧은 앞 오버행.

제조사가 Type 01의 비례를 설명하는 말은 구체적이다. 낮은 지붕선, 짧은 앞 오버행, 긴 보닛, 길게 뻗은 뒤 오버행, 23인치 휠. [3] 얼핏 맞지 않는 말 같지만, 긴 보닛과 짧은 앞 오버행은 모순되지 않는다. 앞 오버행은 앞바퀴 축에서 차체 맨 앞까지의 부분이다. 보닛의 길이는 여기에 앞바퀴 축에서 앞유리 아래까지의 거리를 더한 만큼이다. 앞바퀴를 차의 끝에 바짝 붙여도, 앞유리가 시작되는 지점만 뒤로 물리면 보닛은 길어진다.

측면 사진에서 먼저 눈에 들어오는 것은 유리의 폭이 좁다는 점이다. 어두운 유리 띠는 가늘고, 그 아래로 은색 도어 면이 넓게 펼쳐진다. 지붕은 앞유리 뒤에서 낮게 이어지다 뒤로 내려오며, 뒷바퀴 뒤로 길게 남은 후면과 만난다. 문손잡이는 표면에 낮게 붙어 눈에 잘 띄지 않는다. 창의 높이를 재지 않아도, 어두운 면과 밝은 면의 면적 차이만으로 캐빈은 낮고 얇아 보인다.

사진에서는 긴 차체가 먼저 보이고, 캐빈은 그 뒤쪽에 낮게 얹혀 있다. 재규어의 오래된 GT를 아는 사람에게는 익숙한 구도다. 공간 효율을 가장 먼저 따지는 독자라면 고개를 갸웃할 만하다. 전기 구동계가 요구한 모양은 아니다. 이 비례는 디자인이 내린 결정이다.

CHAPTER 03 / A DIFFERENT LANGUAGE

계보를 잇는 비례,
달라지는 표면.

재규어는 Type 01을 소개하며 E-type과 XJS를 계보로 언급한다. [1] 그렇다고 옛 차의 그릴이나 램프 모양을 옮겨 왔다는 뜻은 아니다. 이어지는 것은 긴 앞부분과 낮은 캐빈이라는 비례다. 표면을 다루는 방식은 그 위에서 달라진다.

Type 00을 내놓은 2024년 발표는 재규어의 새 디자인 철학을 ‘Exuberant Modernism’이라고 불렀다. 재규어는 전기차 시장에서 서로 닮아 가는 형태를 피하고, 브랜드의 고객층과 위치까지 바꾸겠다고 설명했다. 2026년 JLR 자료 역시 Jaguar를 그룹 안의 다른 브랜드와 구별되는 전기차 브랜드로 자리매김한다. [2, 5] 새 디자인 언어는 동력원이 바뀌었음을 알리는 데서 그치지 않고, 멀리서도 다른 차로 보이는 것까지 겨냥한다.

뒤쪽 디테일 사진에서는 면과 면이 만나는 선이 또렷하다. 옆창의 뒤쪽 모서리는 날카롭고, 그 아래 어깨에는 한쪽 끝이 뾰족하게 시작하는 길고 밝은 선이 지나간다. 곡면으로 부드럽게 이어 붙이지 않고, 각이 다른 면을 맞대어 빛을 나눈다. 그래도 납작해 보이지는 않는다. 밝은 선 아래로 면이 완만하게 부풀어 뒷바퀴 쪽으로 내려가기 때문이다.

제조사 FAQ는 프레임리스 도어, 즉 유리 둘레에 금속 틀이 없는 문과, 창과 차체 사이에 눈에 띄는 트림(장식 띠)을 남기지 않는 처리를 강조한다. [4] 틀도 띠도 없으면 이음매를 가려 줄 것이 없다. 문과 차체가 만나는 틈, 유리가 놓인 자리의 간격이 그대로 보인다. 뒤쪽 디테일 사진에서도 문의 경계는 가는 선 하나로 내려온다. 그래서 Type 01의 간결함은 요소를 몇 개 덜어냈느냐보다, 이음매를 얼마나 가지런히 맞췄느냐로 판단해야 한다.

CHAPTER 04 / TYPE 00 TO TYPE 01

선언에서,
하나의 자동차로.

Type 00은 디자인 비전 콘셉트, Type 01은 그 뒤를 잇는 양산 모델입니다.

Type 00은 버터플라이 도어와 단순한 옆창 덕에 차 전체가 하나의 조각처럼 보인다. Type 01에서는 앞뒤 문과 옆창의 구획, 바깥에 달린 미러가 눈에 들어온다. 네 명이 타는 구조를 받아들이면서도 면은 깨끗하게 남기려 한 흔적이 보인다.

Type 00의 유리 없는 테일게이트와 수평 Strikethrough 그래픽은 2024년 콘셉트의 특징으로 명시됐다. 이것을 Type 01의 확정 사양으로 옮겨 적을 수는 없다. Type 01 발표는 깨끗한 표면과 함께 공기 흐름을 바꾸는 능동형 베인, 전개식 스포일러를 설명한다. 표면을 깨끗하게 두는 일과 공기 흐름을 조절하는 일을, 이제 실제로 달리는 차 한 대에서 함께 해결해야 한다. [3, 5]

실내에서는 연결이 더 구체적이다. Type 00에는 황동, 트래버틴과 직물, 실내를 길게 가르는 중심 구조가 제안됐다. Type 01의 공식 설명은 황동을 연상시키는 양극산화 알루미늄 마감재와 트래버틴에서 영감을 얻은 색조를 말한다. [3–5] 돌과 금속의 이름이 반복된다고 해서 소재와 제작 방식까지 같다고 볼 수는 없다. 콘셉트의 분위기가 이어지더라도, 양산차의 재료와 사용성은 다시 설계된다.

양산차가 된다는 것은 콘셉트의 인상 가운데 무엇을 남길지 고르는 일이다. Type 01에서는 긴 비례와 넓은 면이 그 역할을 맡는다. 문의 구획과 공기 흐름을 조절하는 장치에는 다른 사정이 드러난다. 실제 도로를 달리고 네 명이 타야 하는 차가 받아들여야 했던 조건이다.

CHAPTER 05 / WHAT CHANGES

먼저 읽히는 것,
아직 묻는 것.

Type 01의 가장 큰 장점은 눈이 가는 순서가 분명하다는 것이다. 먼저 낮고 긴 덩어리가 보이고, 그다음 큰 바퀴와 어두운 유리, 마지막으로 얇은 경계와 표면 위의 빛이 들어온다. 선을 덧대어 속도를 만드는 차가 아니다. 긴 면과 작은 캐빈의 대비 하나로 첫인상이 정해진다.

이 선명함은 질문도 함께 남긴다. 넓은 차체 면과 낮은 유리의 비율은 보는 사람에 따라 단단하게도, 무겁게도 느껴진다. 긴 보닛 역시 재규어의 GT를 떠올리게 하지만, 전기차가 얻은 자유가 타는 사람에게 무엇으로 돌아갔는지는 따로 물어야 한다. 낮은 유리가 실내 공간과 시야에 어떤 영향을 주는지는 사진만으로 알 수 없다.

이 비례가 디자인사에서 어떤 평가를 받을지는 아직 알 수 없다. 실제 도로에서의 모습, 시간이 지난 뒤의 반응, 뒤따를 모델들이 판단을 바꿀 것이다. 지금 확인되는 것은 Type 00의 콘셉트가 4도어 GT인 Type 01로 이어졌고, 그 사이에 긴 보닛과 낮은 캐빈이 남았다는 사실까지다. 사진만 놓고 보면 마지막 장면이 가장 설득력 있다. 위에서 내려다본 Type 01은 좁은 유리 아래로 차체가 넓게 벌어져 있고, 긴 그림자가 가로지르는 길 위에서도 윤곽이 또렷하다.

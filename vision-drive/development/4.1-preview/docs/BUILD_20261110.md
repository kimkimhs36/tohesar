# 4.1 preview build recovery

The two missing `web/drive/*.woff2` files were recovered from the existing
VISION DRIVE simulator assets. Their embedded family names are `BKIT Instrument
04` and `BKIT Text 04`, matching `DESIGN.md`; the corresponding Barlow
Condensed and Pretendard OFL notices are included in `licenses/`.

PlatformIO `espressif32@6.9.0` built the preview successfully. The generated
3,072-byte partition table matched the 4.0 board backup at offset `0x8000`.
The application image is 920,560 bytes with SHA-256
`d0d7963d9551ea8294ee2db84fab68a19ccedb7e89c34cd2017f5b784e268c93`.
On 2026-11-10 the ESP32 at COM14 was confirmed against the full 4.0 backup,
then this app image was written at `0x10000` and verified against the device.
The write tool returned exit code 1 *after* successful readback because a final
message contained a character unsupported by the Windows console encoding.
That message was corrected in `tools/flash.py`; no second write was required.
After reset, the real device reported 4.1.0, camera available, disarmed, both
outputs zero, lease 350 ms, and stream available. JPEG capture and MJPEG
returned HTTP 200, and a STOP request returned `ok: true`. The device-served
HTML and JavaScript matched the built source SHA-256 hashes. Local release
logs record the flash and subsequent validation; they are not part of Git.

The five mocked flash safety tests passed after generating the local release
files, including full-backup restore verification and rejection of corrupt or
unconfirmed restores. The mixer and video UI mock tests also passed. The flash
I/O test cannot run directly in this preview checkout because `web/setup/` is
absent; five synthetic protocol checks passed in an isolated temporary harness
using the existing VISION DRIVE setup code and its esptool-js bundle. This
does not verify a web installer in the preview checkout. Actual restore, motor
movement, disconnect watchdog and iPad operation remain unverified. The motor
power was disconnected for the firmware update. Preserve the 4.0 full backup.

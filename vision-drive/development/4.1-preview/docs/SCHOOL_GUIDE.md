# 학교 실행 안내

상세 설명·실기 체크리스트·복원: https://tohesar.com/vision-drive/guide/

1. 선생님과 제조사 USB-TTL 배선·전압·GPIO0 부트 진입을 확인하고 모터 전원을 분리한다. 바퀴를 띄운다.
2. 데스크톱 Chrome/Edge에서 https://tohesar.com/vision-drive/setup/ 을 연다. 그 기기의 전체 4 MB 플래시를 백업하고 BIN·JSON 둘 다 안전한 곳에 보관한다. BIN에는 기존 Wi-Fi 설정 등이 포함될 수 있다.
3. 도구가 백업 파일·기기·해시를 확인한 뒤 설치 버튼을 사용한다. 기록 후 읽기 검증까지 기다린다. 자동으로 동작이 검증됐다는 뜻이 아니다.
4. 전원을 끄고 GPIO0–GND를 해제한 다음 정상 전원을 켠다.
5. iPad/스마트폰에서 `VISION-DRIVE-…` Wi-Fi에 접속한다. 암호 `BKIT-5023`. 인터넷 없음 표시는 정상이다.
6. Safari 또는 브라우저 주소창에서 `http://192.168.4.1` 을 연다. 화면을 가로로 놓고 손을 비춰 영상이 현재 장면인지 확인한다. LOW·바퀴 띄움부터 `구동 준비`를 누르고 천천히 확인한다.
7. 손을 놓으면 중립, STOP / SPACE / ESC는 잠금이다. 멈추지 않으면 로봇의 물리 전원 스위치를 끈다. 연결이 끊긴 뒤에는 수동으로 다시 준비한다.
8. FIELD NOTES의 통신 진단은 모터 없이 HTTP 응답 시간을 측정한다. `시운전 기록`에서 메모와 HTML 보고서·JSON을 저장할 수 있다. 실제 영상 지연이나 바퀴 움직임을 측정하는 센서 기능은 아니다.

이후 조종에는 노트북, USB, 컴파일, PowerShell이 필요 없다. 실제 Wi-Fi, iPad Safari, 모터 및 복원은 미검증 상태이므로 시연 전 1회 인수 시험이 필요하다.

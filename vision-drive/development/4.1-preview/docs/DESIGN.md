# Driver’s instrument / 04

차를 다루는 도구와 자동차 문화 저널이 같은 프로젝트임을 느끼게 하되, 운전 중에는 문화적 표현이 조작을 방해하지 않게 했다.

- 밝은 종이색 바탕, 검푸른 광학 창, 주황색 정지 버튼. 발광·네온·카드 그리드 대신 수평 기준선과 여백으로 위계를 만든다.
- 카메라는 1차, 손 조작은 2차, 설정은 3차. 아이패드 가로에서 영상·출력·손 조작·STOP이 동시에 보인다. 1024×768과 1194×834에서 렌더링했다.
- 주행 명령과 실제 센서값을 구분한다. 메인 수치는 PWM 제한 비율이다. L/R은 명령이며 속도계 모양의 가짜 km/h나 배터리 표시를 쓰지 않는다.
- 터치는 고정 원점 아날로그 패드, 키보드와 방향 버튼도 지원한다. 입력을 놓을 때 중립으로 돌아온다. 설정은 구동 잠금 중에만 바꾼다.
- 모바일 세로는 영상 바로 다음에 조작부를 두고 출력 설정은 아래로 내렸다. 구동 중 STOP은 하단 고정이다. 사진·구도선 등은 카메라 가장자리에 남긴다.
- TOHEŞAR는 절제된 편집 디자인, TEAM BKIT은 도면 표기·장비 번호·구조의 정직함으로 표현한다. 브랜드 로고를 과도하게 반복하지 않는다.
- 공개 랜딩 페이지는 플랫폼을 직접 그린 엔지니어링 일러스트와 실제 렌더링한 조종석으로 설명한다. 실물 사진·실제 영상으로 오인하지 않도록 표기한다.
- 로봇 안에서도 로컬 글꼴을 사용한다. Pretendard와 Barlow Condensed를 필요한 글리프만 추려 BKIT Text 04·BKIT Instrument 04로 이름을 바꿔 포함했다. 나머지 문자는 시스템 서체로 표시한다. 공개 사이트의 원본 서체와 OFL 고지도 함께 제공한다.

반복 개선 근거: 처음 렌더링에서 공개 페이지의 이미지 최소 너비 때문에 가로 넘침을 발견해 grid 항목 min-width를 수정했다. 모바일에서 설정이 영상과 조작부를 분리하던 순서를 재배치했고, 구동 중 고정 STOP과 키보드 SPACE의 포커스 처리를 보강했다. 최종 화면은 screenshots/에 있으며 실제 로봇 화면처럼 보이는 수신 예시는 MOCK CAMERA로 표시했다.

설치가 끝나면 노트북은 내려놓아도 됩니다.
이 도구는 데스크톱 Chrome·Edge의 USB 시리얼을 사용합니다.

실제 기기에 쓰는 단계입니다. 이 버전은 컴파일·모의 테스트를 통과했지만 KS5023 실물 시험은 아직 하지 않았습니다. 선생님과 함께 바퀴를 띄우고 전원·배선을 확인하세요. 연결만으로는 플래시하지 않습니다.

01

USB 연결과 기기 확인

KS5023의 제조사 업로드 배선을 그대로 사용하세요. 모터 전원은 끄거나 분리하고, USB-TTL은 제조사 기준 전압·공통 GND를 확인합니다. BOOT 진입은 GPIO0–GND 연결 후 리셋입니다. 자동 진입이 안 될 때만 수동 진입하세요.

연결된 기기 없음

02

기존 정상 펌웨어를 통째로 보관

4 MB 플래시를 읽고 기기 MD5와 비교합니다. BIN과 JSON 기록을 모두 저장하고, 다운로드한 BIN을 다시 선택해야 설치 버튼이 열립니다. 백업에는 기존 Wi-Fi 설정이 포함될 수 있으니 공개 업로드하지 마세요.

백업 전

03

VISION DRIVE 설치

배포된 펌웨어의 SHA-256을 확인한 뒤 기록하고, 다시 읽어 파일 해시를 비교합니다. 백업이 검증되지 않았거나 기기가 다르면 진행하지 않습니다. 쓰는 동안 USB를 분리하지 마세요.

R

기존 상태로 복원

이 기기에서 저장한 stock-…bin과 함께 내려받은 JSON 기록을 선택하세요. 기기의 MAC과 파일 해시가 모두 일치해야 기록합니다. 복원 후 GPIO0–GND를 해제하고 재시작하세요.

기기를 연결하면 진행 상태가 여기에 표시됩니다.

기술 로그
설치 완료 후: GPIO0–GND 해제 → 전원 재시작 → VISION-DRIVE-… Wi-Fi 연결 (암호 BKIT-5023) → http://192.168.4.1. iPad·스마트폰에서는 이후 이 주소만 열면 됩니다.
설치 도구의 오픈소스 고지: esptool-js · SparkMD5 · pako · atob · zlib.
USB 드라이버가 없으면 제조사 USB-TTL 드라이버 설치가 처음 한 번 필요할 수 있습니다. Safari·iPad에서는 USB 설치를 지원하지 않으며, 설치 후 조종은 Safari에서 가능합니다. 임의 보안 설정 변경은 필요하지 않습니다.

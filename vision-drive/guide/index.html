FIELD GUIDE / 기술실에서 읽는 안내

준비는 한 번.
운전은 손안에서.

처음 설치에는 USB를 연결한 데스크톱 Chrome·Edge가 필요합니다. 설치 후에는 아이패드나 스마트폰에서 로봇 Wi-Fi에 연결해 조종석을 엽니다.

실물 기기를 연결하지 않은 개발 결과입니다. 첫 업로드와 아래 인수 시험은 선생님과 함께 진행하세요. 실제 기기를 자동으로 플래시하는 작업은 수행하지 않았습니다. 기존 정상 펌웨어의 정확한 복원본은 해당 기기를 전체 백업해야 확보됩니다.

1. 처음 한 번: 기존 상태를 보관하고 설치

  1. 배터리·모터 전원을 끄고, 바퀴가 바닥에 닿지 않게 고정합니다. 제조사와 다른 핀 배선·SD 카드가 있으면 먼저 제거·확인하세요.
  2. 제조사 설명서의 USB-TTL 배선을 사용합니다. TX↔RX, 공통 GND와 전원 규격을 확인하세요. GPIO0–GND를 연결한 뒤 리셋하여 다운로드 모드에 들어갑니다. USB 시리얼과 카메라의 전원 부족이 없도록 합니다. 모터 전원과 USB 전원을 임의로 동시에 연결하지 마세요.
  3. 백업·설치 도구에서 포트를 선택합니다. 연결만으로 플래시에 쓰지 않습니다.
  4. 전체 4 MB를 읽고 검증합니다. stock-…bin을 저장하고 ‘백업 JSON 기록 저장’도 누릅니다. 저장한 BIN을 다시 선택해 일치 여부를 확인합니다. BIN과 JSON은 함께 별도 USB 등에 보관합니다. 기존 Wi-Fi 정보가 포함될 수 있으니 공개하지 마세요.
  5. 모터 전원 분리 확인란을 선택하고 ‘검증된 펌웨어 설치’를 누릅니다. 읽기 검증까지 완료될 때까지 기다립니다.
  6. 연결 해제 → 전원 끄기 → GPIO0–GND 해제 → 제조사 정상 전원 구성으로 전원 켜기 순서로 진행합니다.

Web Serial 사용이 학교 정책에 의해 막히면 보안 설정을 끄지 마세요. 선생님이 허용한 컴퓨터에서 처음 한 번 설치하거나 패키지의 Python 대체 도구를 사용하세요. USB 드라이버가 없는 경우 제조사 드라이버 설치가 처음 한 번 필요할 수 있습니다.

2. 매번 시연할 때: Wi-Fi → 주소 → 준비

  1. 로봇을 켜고 아이패드·스마트폰 Wi-Fi에서 VISION-DRIVE-…를 선택합니다. 암호는 BKIT-5023입니다. ‘인터넷 없음’이 정상입니다. 이 네트워크에 계속 연결합니다.
  2. 브라우저 주소창에 검색어가 아닌 http://192.168.4.1을 입력합니다. HTTPS가 아닙니다. 외부 CDN·앱 설치·컴파일·PowerShell·노트북 서버는 필요 없습니다.
  3. 가로 방향으로 놓고 카메라 앞에서 손을 움직여 현재 영상인지 확인합니다. 기본 출력은 LOW(85/255)입니다.
  4. ‘구동 준비’를 누릅니다. 조이스틱·방향 버튼·WASD/방향키를 누르는 동안 이동하고, 놓으면 중립 명령을 보냅니다. 좌우는 차동 회전이며 자동차 조향각이 아닙니다.
  5. STOP / SPACE / ESC는 정지와 잠금입니다. 창 이탈·화면 숨김·영상 오류·명령 응답 지연도 잠급니다. 재연결해도 자동 출발하지 않으며 다시 준비해야 합니다.

출력·수동 좌우 보정은 잠금 상태에서 바꿉니다. 보정이 양수면 왼쪽 출력을, 음수면 오른쪽 출력을 최대 20% 낮춥니다. 이 보정은 좌우 PWM 명령을 조절할 뿐, 센서가 없으므로 차가 실제로 직진하는지 감지하거나 자동으로 안정화하지 못합니다. LED는 구동 준비 중에만 켤 수 있고, 잠금 시 소등 명령을 냅니다.

공용 암호를 사용하는 교실용 AP입니다. 한 번에 단말 1대만 연결할 수 있지만 한 단말의 중복 탭도 제어권을 방해하므로 조종석은 한 탭만 여세요. 공공장소·인터넷 노출용 원격 제어 시스템으로 사용하지 마세요.

3. 첫 실기 인수 시험

각 단계는 바퀴를 들고 LOW부터 진행합니다. 모터 방향이나 예상 동작이 다르면 즉시 전원을 끄고 배선과 제조사 모델을 확인합니다.

시험확인할 실제 결과
방향·놓기전진·후진·양쪽 회전이 맞고 손을 놓으면 출력이 내려가는지
STOP·화면 잠금회전 중 STOP, 앱 전환, 화면 잠금 후 구동 정지·재준비 요구
Wi-Fi 완전 단절구동 중 단말 Wi-Fi를 끈 뒤 별도 촬영으로 출력 중단 시간을 측정. 펌웨어 기준은 마지막 유효 명령 후 350 ms + 태스크 스케줄 지연
영상 단절카메라 케이블을 전원이 켜진 상태에서 뽑지 않음. 개발 시험 장치로 영상 경로를 차단했을 때 잠금
전원·재부팅모터 시동 중 ESP32 재부팅·영상 손실 여부, 전원을 다시 켜도 움직이지 않는지
LED·출력·보정LOW/MID/HIGH·수동 보정 반영. LED 켜기·잠금 후 소등. 뜨거워지면 즉시 중단
사진·녹화저장 사진과 최대 60초 녹화 파일이 재생되는지. 녹화 지원은 브라우저마다 다름
복원같은 기기 백업 BIN+JSON으로 복원하고 기존 제조사 영상·모터 기능을 확인

350 ms는 차량의 완전 정지 시간을 보장하지 않습니다. 관성·노면·모터 드라이버의 동작에 따라 정지 거리가 달라집니다. 저전압·프로세서 고장·배선 문제에 대한 물리적 비상 정지 장치는 로봇 전원 스위치입니다.

4. 연결이 안 될 때

  1. 로봇 Wi-Fi를 유지하세요. 인터넷이 없다는 이유로 다른 Wi-Fi·모바일 데이터로 자동 전환되지 않았는지 확인합니다.
  2. 주소는 http://192.168.4.1입니다. 학교망 IP나 공개 사이트에서 직접 조종하지 않습니다.
  3. 다른 연결 단말·제조사 페이지·중복 탭을 닫습니다. AP는 단말 1대만 허용합니다.
  4. 카메라 오류가 표시되면 전원을 끄고 리본 케이블을 확인합니다. 영상이 없으면 안전상 구동 준비가 차단됩니다.
  5. 모터 시작 때 재부팅하면 배터리·전원 접점·공급 전류를 점검합니다. 새 펌웨어는 브라운아웃 감지를 끄지 않습니다.
  6. 문제가 계속되면 로봇 전원을 끄고 조종석의 FIELD NOTES에서 통신 진단을 실행하고 시운전 보고서 또는 JSON 기록을 내보내세요. 통신 진단은 모터를 움직이지 않고 로봇 HTTP 응답 시간 20회를 측정합니다. 화면 지연이나 실제 움직임을 측정한 값은 아닙니다.

5. 기존 정상 펌웨어로 되돌리기

  1. 모터 전원을 분리하고 GPIO0–GND 연결 후 리셋하여 다운로드 모드로 들어갑니다.
  2. 설치 도구에서 같은 시리얼 기기에 연결합니다. ‘기존 상태로 복원’에서 해당 기기의 백업 BIN과 JSON을 선택합니다.
  3. 기기 MAC·4 MB 크기·SHA-256을 검증한 뒤, 복원 확인란을 선택하고 복원을 실행합니다. 완료 후 읽기 검증도 확인합니다.
  4. 연결 해제 → 전원 끄기 → GPIO0–GND 해제 → 재시작합니다. 기존 Wi-Fi 환경에서 제조사 페이지와 기능을 확인합니다.

제조사 예제는 패키지의 vendor/codes/11_4_Video_Car에 원형대로 보관했습니다. 이 소스는 이 기기의 기존 Wi-Fi 설정을 알지 못하므로, 전체 플래시 백업의 대체물이 아닙니다. 해당 기기의 백업 없이 ‘원래 상태로 완전히 복원했다’고 말할 수 없습니다.

선생님 앞에서 설명하는 30초

“VISION DRIVE는 ESP32-CAM 로봇을 위한 웹 조종석입니다. 처음 한 번 설치하면 로봇이 Wi-Fi와 화면을 직접 제공해서 노트북 서버가 필요 없습니다. 화면은 요청한 방향과 출력을 보여 주며, 센서가 없는 속도나 배터리 수치는 표시하지 않습니다. 연결을 잃으면 로봇 내부의 명령 만료 로직이 출력을 내리고, 다시 연결해도 사람이 준비를 눌러야 움직입니다. 오늘은 먼저 바퀴를 띄워 정지 동작부터 시연하겠습니다.”

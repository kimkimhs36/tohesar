# TOHEŞAR — MEMORY ALLOY / FOLDED RECORD

Experimental art-direction prototype (Stage 02), **not the official homepage**.

## Preview

Serve the repository root as static HTTP and open `/memory-alloy/`. The prototype uses its existing `/assets/wordmark-hd.png` (relative to project root). 

## Files

- `index.html` — masthead, editorial typography, stage, scroll and navigation.
- `style.css` — mobile-first layout, palette, fallback.
- `sculpture.js` — original WebGL2 parametric folded titanium and translucent recording-film sculpture.

## Scope / safeguards

- New, standalone `memory-alloy/` route only; no edits to `index.html`, `world/`, `symbol/`, `history/`, `journal/`, or Pages configuration.
- No fake portfolio and no external car models.
- Existing wordmark retained; no AI-generated text reconstruction.
- Native vertical scrolling controls two visual scenes.
- Reduced-motion and WebGL fallbacks exist.

## QA status

- JavaScript syntax: checked in local build.
- Chromium layout and scroll, iPhone-size and iPad-size viewports: checked in constrained environment.
- WebGL2 GPU render and physical iPhone Safari: **not yet verified**; inspect on real device before visual approval.

**Do not merge into main or publish over tohesar.com without the user's explicit approval.**

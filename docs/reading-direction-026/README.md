# 026 읽기 지면 검토

`after-home-direct-390.png`는 홈 도입의 불필요한 안내 문구와 링크를 제거한 상태다. 홈의 미니카 안내와 중복 탐색 영역은 이후 제거했으며, 기사 사진과 제목에서 본문으로 직접 이동한다. 나머지 이미지는 검토 중간에 촬영한 화면으로 최종 문구나 복귀 링크가 다를 수 있다.

Chromium의 화면 및 동작 검사를 기록했다. iPhone Safari 실기기 검사는 하지 않았다. 기존 004·과거 화보 원본은 보관되어 있으며, 현재 저널과 기사 동선에서는 사진 형태의 AI 자동차 장면을 제외했다.

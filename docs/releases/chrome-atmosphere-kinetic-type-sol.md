# CHROME ATMOSPHERE / KINETIC TYPE — SOL EXPERIMENT

Work branch: `experiment/chrome-atmosphere-sol-001`
Derived from Astra's preserved `experiment/chrome-atmosphere-001` at `d9dc069`.

## New visual direction
The display type itself is a 3D sculpture. The original OFL-licensed Instrument Serif is raster-contoured at runtime and reconstructed into beveled and extruded physical meshes, shaded with the scene's existing custom studio reflections.

- Opening: **CHROME**, a solid reflective sculptural word, layered over the liquid loop
- Scroll fracture: letters separate, tumble in depth, and **their geometry actually bends and melts** — not just CSS character transforms
- Second scene: **STATES** coalesces out of scattered dimensional characters alongside the editorial "Between" composition
- Continuous camera/loop/glass movement retained from Astra's earlier work
- Existing flat headings stay as fallback when browser font loading or WebGL fails
- iPhone-first framing, larger landscape composition, reduced-motion considerations

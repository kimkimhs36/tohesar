# 탐색 개선 검증

홈 오프닝은 유지하고 그 다음 헤더를 고정했다. 공통 메뉴는 저널, 둘러보기, 뉴스룸 및 전체 구조로 연결된다. `/journal/explore/`는 분야별 진입점이며 `/sitemap/`은 계층과 기사 경로를 보여준다. 공통 원본은 `journal/partials/`에 있고 발행 빌드 마지막에 각 페이지와 사이트맵을 다시 생성한다.

Chromium에서 홈·저널·디자인·뉴스룸·F40·Giulia·사이트맵·둘러보기 8개 화면을 375/390/430/768/1440px로 확인했다. 메뉴 열기, Escape와 바깥 클릭, HTTP 응답, 가로 넘침, 이미지와 JS 오류를 점검했고 홈 고정 헤더와 뒤로 가기 복귀를 확인했다. `captures/`에 전후 및 375/390/430px 캡처를 저장했다. 서버를 127.0.0.1:8767에서 기동한 뒤 `python3 scripts/verify_navigation_019.py`로 재현한다. 발행 링크 검사와 기존 발행 테스트 8개, 데이터 기사 테스트 7개가 통과했다.

이 환경에서 WebKit의 시스템 라이브러리가 누락되어 실제 iPhone Safari 엔진이나 실기기는 검증하지 못했다. Chromium 모바일 뷰포트 결과와 구별해야 한다. 기존 본문에 남은 장식 기호 및 개별 페이지 전용 탐색 요소는 추가 시각 검토가 필요하다. 승인된 지면의 원본 및 운영 브랜치는 변경하지 않았다.
